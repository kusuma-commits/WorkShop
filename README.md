## 📝 Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi yang Disampaikan
Selama sesi Workshop Day 1, materi yang disampaikan terbagi ke dalam beberapa fokus utama:

#### A. Pengenalan Akademik & Fasilitas Jurusan TIK PNJ
- **Struktur Organisasi Jurusan:** Mengenal jajaran pimpinan jurusan, ketua program studi (KPS), dosen pembimbing, serta peran masing-masing unit akademik di TIK PNJ.
- **Fasilitas Laboratorium:** Pengenalan fungsi laboratorium komputer, jaringan komputer, serta multimedia/multipel studio yang mendukung perkuliahan praktikum, disertai tata tertib dan etika penggunaan fasilitas laboratorium.
- **Model Pembelajaran Inovatif:** Pemaparan mekanisme pembelajaran berbasis proyek (*Project-Based Learning* / PBL dan PjBL), serta program Merdeka Belajar Kampus Merdeka (MBKM / MSIB) untuk mempersiapkan mahasiswa menghadapi kebutuhan industri terkini.
- **Profil Lulusan & Kurikulum:** Memahami capaian pembelajaran lulusan (CPL), kurikulum berbasis *Outcome-Based Education* (OBE), dan jalur karier profesional bagi lulusan TIK.

#### B. Pengenalan Git dan GitHub (Version Control System)
- **Konsep Version Control:** Memahami fungsi Git dalam melacak riwayat perubahan kode (*history tracking*), kolaborasi antarpengembang tanpa risiko timpa-menimpa file, serta kemampuan *revert* perubahan jika terjadi kesalahan (*bug*).
- **Perintah Esensial Git:**
  - `git init`: Menginisialisasi repositori lokal.
  - `git clone <url>`: Mengunduh repositori dari remote server (GitHub) ke lokal.
  - `git add <file>`: Menambahkan file ke staging area.
  - `git commit -m "<pesan>"`: Menyimpan snapshot perubahan dengan deskripsi ringkas.
  - `git push origin <branch>`: Mengunggah komit lokal ke repositori remote di GitHub.
  - `git pull`: Menarik pembaruan terkini dari repositori remote ke mesin lokal.
  - `git status` & `git log`: Memeriksa kondisi *working directory* dan melihat riwayat komit.
- **Visibilitas Repositori:** Membedakan repositori *Private* untuk proyek tertutup dan *Public* untuk dokumentasi umum, kolaborasi terbuka, dan portofolio.

#### C. Standarisasi Dokumentasi Teknis dengan Markdown (`README.md`)
- Peran file `README.md` sebagai gerbang utama pengenalan proyek.
- Struktur standar dokumentasi: judul proyek, identitas penulis, deskripsi, tujuan, rangkuman, cara instalasi/penggunaan, dan hierarki folder.
- Penerapan sintaks Markdown: *Headings*, *Lists*, *Tables*, *Code Blocks*, *Hyperlinks*, *Blockquotes*, dan *Badges*.

### 2. Poin-Poin Penting & Pengetahuan Baru yang Dipelajari

1. **Pentingnya Version Control dalam Dunia Profesional:**
   Penggunaan Git bukan sekadar tempat mencadangkan file, melainkan standar industri dalam kerja sama tim pengembang perangkat lunak modern untuk menjaga integritas kode dan efisiensi alur kerja (*workflow*).
2. **Kekuatan Dokumentasi yang Bersih dan Komprehensif:**
   File `README.md` yang tersusun rapi mencerminkan profesionalitas seorang developer. Dokumentasi yang baik mempermudah pembaca maupun penguji dalam memahami esensi tugas tanpa ambigu.
3. **Penyusunan Struktur Repositori yang Rapi:**
   Pemisahan antara dokumen utama, materi, dan catatan belajar ke dalam folder terpisah (`materi/`, `catatan/`) sangat krusial untuk skalabilitas proyek jangka panjang.
4. **Wawasan Kesiapan Karier di Jurusan TIK PNJ:**
   Memahami sejak dini keterkaitan kurikulum akademik dengan program praktik industri (PBL/MBKM) membantu dalam memetakan target kompetensi dan spesialisasi keahlian yang ingin ditekuni.
