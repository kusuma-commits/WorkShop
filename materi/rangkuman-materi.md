## 1. Pengenalan Akademik Jurusan Teknik Informatika & Komputer (TIK)

### A. Visi dan Misi Jurusan
- Menghasilkan lulusan yang kompeten, profesional, dan berdaya saing global di bidang rekayasa perangkat lunak, sistem cerdas, dan infrastruktur komputasi.
- Mengembangkan riset terapan serta pengabdian masyarakat yang memberikan dampak langsung bagi industri dan masyarakat luas.

### B. Kurikulum Berbasis OBE (Outcome-Based Education)
- Pendekatan pembelajaran yang berorientasi pada pencapaian kemampuan akhir mahasiswa (Course Learning Outcomes / CLO).
- Penguatan integrasi antara teori di perkuliahan kelas dan praktik intensif di laboratorium.
- Program MBKM / MSIB yang memfasilitasi mahasiswa magang bersertifikat dan studi independen di perusahaan teknologi terkemuka.

### C. Pengenalan Fasilitas Laboratorium TIK
- Laboratorium Pemrograman Dasar & Lanjut
- Laboratorium Jaringan & Keamanan Siber
- Laboratorium Rekayasa Perangkat Lunak & Basis Data
- Laboratorium Multimedia & Pengolahan Citra

## 2. Pengenalan Version Control System (VCS) & GitHub

### A. Definisi & Signifikansi
- **Version Control:** Alat pelacak setiap baris kode dan revisi proyek.
- Menghindari risiko kehilangan file sumber dan memudahkan kolaborasi tim dalam skala besar tanpa khawatir menimpa kode rekan kerja.

### B. GitHub sebagai Platform Kolaboratif
- GitHub bertindak sebagai cloud-based hosting untuk repositori Git.
- Fitur utama meliputi Pull Request, Issue Tracker, GitHub Actions (CI/CD), dan GitHub Pages.
- Menggunakan GitHub secara aktif menjadi standar industri dalam membangun portofolio seorang software engineer.

---

## 3. Dokumentasi Teknis Menggunakan README.md

- `README.md` adalah dokumen pertama yang dilihat ketika seseorang mengunjungi repositori.
- Dokumentasi yang baik mencakup identitas pengembang, latar belakang proyek, prasyarat sistem, langkah instalasi/penggunaan, serta struktur direktori.
- Menulis dokumentasi yang rapi adalah bagian integral dari etika *clean code* dan profesionalisme seorang pengembang perangkat lunak.
